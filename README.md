WICKWARDEN is an original twin-stick arena shooter in vanilla JavaScript and Canvas 2D — no libraries, everything drawn and sounded in code. You are the last lightkeeper of Gloamharbour, and the light is the only weapon: your lantern burns oil and throws the pool of light where the Hollow can be hurt — a foe standing in darkness takes only a fraction of every hit, so where you stand is a weapon. Kills and embers feed the oil; the Great Lantern's sweeping beam, the four quay braziers and dropped flares are the other ground you can fight from. Escalating waves of Drifters, Spitters, Blooms and Lancers, a draft of three stackable upgrades after every wave (thirteen now, three of them for the lantern itself), and the Hollow Sovereign, a three-phase boss whose later phases eclipse your flame, every fifth wave. To play it, serve the game/ folder with any static file server (or run `node serve.ts` here) and open it in a desktop browser: WASD to move, mouse to aim, hold click to fire, Shift to dash.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
