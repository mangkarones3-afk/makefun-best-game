VOIDSTRIKE is an original twin-stick arena shooter in vanilla JavaScript and Canvas 2D — no libraries, everything drawn and sounded in code. Pilot the Warden and hold the gate against the Hollow swarm: escalating waves of Drifters, Spitters, Blooms and Lancers, a draft of three stackable upgrades after every wave, and the Hollow Sovereign, a three-phase boss, every fifth wave. To play it, serve the game/ folder with any static file server (or run `node serve.ts` here) and open it in a desktop browser: WASD to move, mouse to aim, hold click to fire, Shift to dash.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
